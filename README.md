# Doyeon Lee — Portfolio 웹사이트

블랙 & 화이트, 얇은 선만 사용한 미니멀 포트폴리오 사이트입니다.
코드를 몰라도 **관리도구**로 작업물을 추가·수정할 수 있습니다.

---

## 딱 3가지만 기억하세요

| 하고 싶은 것 | 방법 |
|---|---|
| 사이트 미리보기 | **`미리보기.bat`** 더블클릭 |
| 작업물 추가/수정 | **`관리도구.bat`** 더블클릭 |
| 인터넷에 올리기 | [docs/배포가이드.md](docs/배포가이드.md) 참고 (폴더를 드래그하면 끝) |

- 관리도구에서 수정한 뒤 **우측 상단 「변경사항 저장」**을 꼭 누르세요.
- 저장 후 미리보기 탭을 **새로고침**하면 반영됩니다.
- 자세한 사용법: **[docs/사용법.md](docs/사용법.md)**

> 필요 환경: Windows + Edge 또는 Chrome (둘 다 기본 설치되어 있는 것으로 충분합니다)

---

## 폴더 구조

```
Doyeon_portfolioweb/
├── 미리보기.bat        ← 사이트 미리보기 (더블클릭)
├── 관리도구.bat        ← 작업물 추가/수정 (더블클릭)
├── index.html          사이트 본체
├── css/, js/           디자인과 동작 코드
├── lib/                three.js (3D 표시용)
├── assets/fonts/       Pretendard 폰트
├── assets/pattern/     홈 화면의 석고 문양 (마우스를 올리면 입체로 떠오름)
├── content/
│   ├── data.js         ★ 모든 글/목록 데이터 (관리도구가 자동으로 수정)
│   ├── backups/        저장할 때마다 자동 백업 (최근 30개)
│   └── media/          ★ 업로드한 이미지·영상·3D 파일
├── admin/              관리도구 화면
├── tools/serve.ps1     로컬 서버 (bat이 실행함)
└── docs/               사용법·배포 가이드
```

★ 표시된 두 곳이 "내용물"의 전부입니다. 이 폴더 전체를 복사하면 사이트 전체가 복사됩니다.

## 자주 묻는 질문

**Q. 관리도구가 "로컬 서버가 필요합니다"라고 해요.**
`관리도구.bat`으로 열어야 합니다. (검은 서버 창이 함께 열리는데, 닫으면 저장이 안 되니 작업 중에는 켜 두세요.)

**Q. 실수로 내용을 날렸어요.**
`content/backups/` 안에 저장 시점마다 백업이 있습니다. 가장 최근 파일을 `content/data.js`로 복사(이름 변경)하면 복구됩니다.

**Q. 3D 파일은 어떤 형식인가요?**
`.glb` 파일을 권장합니다 (Blender: 파일 → 내보내기 → glTF 2.0). 자세한 권장 규격은 [docs/사용법.md](docs/사용법.md) 참고.

**Q. 사이트가 인터넷에서도 관리도구로 수정되나요?**
아니요. 관리도구는 내 컴퓨터에서만 동작합니다(안전). 수정 후 다시 배포(폴더 드래그)하면 온라인에 반영됩니다.
